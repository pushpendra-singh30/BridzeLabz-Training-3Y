Filters

Change visual appearance using CSS.

filter: grayscale(100%);

Media Queries

Apply styles according to screen size.

@media (max-width: 700px)

Responsive Design

Make layouts adapt to different devices.

Typography

Use relative units for flexible text.

font-size: clamp(1rem, 2vw, 1.5rem);
