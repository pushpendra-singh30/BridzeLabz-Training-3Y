Responsive Design

Responsive design allows a webpage to adapt its layout, images, and typography to different screen sizes.

Flexbox, Grid, media queries, relative units, and flexible images help create responsive websites.

Cheat Sheet Preview

  • Grid - page layout
  • Flexbox - alignment
  • Media Queries - breakpoints
  • Clamp - responsive typography
